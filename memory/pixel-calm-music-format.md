The user approved cat-no-sweet v2 and said "belə videolar etsən yaxşı olar, fərqli mövzularda" (make videos like this, on different topics). This is now the main format:
- detailed 2D pixel art (the SDF + dither engine; the cat in art7.ts is the quality bar);
- an original, surprising, shareable topic with a "send this to X" ending;
- ~18 s, with the hook frame showing the punchline;
- a calm original melody plus synced SFX, and no narration.

**Why:** IG metrics showed views stuck at 2–3k with almost no shares. The user also noticed that big pixel channels use catchy melodies and random fun facts.

**How to apply:**
- Each video gets a new setting, palette and transition (see [[vary-each-video]]).
- Pick topics with [[topic-research]] and a clear share target (cat owners, dog owners, gym friends…).
- Sound per [[sfx-only-no-music]] (updated).
- Template project: output/work/cat-no-sweet.
